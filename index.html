A Solução

O JOVI Study Mode foi criado para facilitar a organização de conteúdos acadêmicos fotografados pelo celular.

Organizar fotos

Cadastre fotos acadêmicas informando o nome e a matéria relacionada.

Separar matérias

Organize os conteúdos em diferentes matérias para facilitar o acesso.

Identificar conteúdos

O sistema pode identificar matérias através de palavras presentes no conteúdo.

Público-Alvo

A solução é voltada principalmente para estudantes que utilizam o celular para registrar seus conteúdos acadêmicos.

Estudantes

Pessoas que fotografam aulas, exercícios, anotações e outros materiais escolares.

Organização

O JOVI facilita encontrar o conteúdo necessário durante os estudos.
